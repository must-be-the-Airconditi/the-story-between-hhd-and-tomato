# hhd & tomato

> 作者：**NormalNPC** & **simpleNPC**

## 📖 概述

这是一个关于 **hhd** 与 **tomato** 的故事。

hhd，十九岁的龙会集团最高董事长，一条活了不知多少年的真龙。tomato，二十岁的市场部组长，入职一年就凭实力让全公司闭嘴的年轻人。

故事的起点是一份Q3方案，终点是一张“申请通过，沙发床不要，你搬到我隔壁办公室”的便签。

从年会上天台的那句“我有个申请”，到办公室里系错的衬衫扣子——这不是什么惊天动地的传奇，只是一个活了很久的龙，和一个认真喜欢她的人，在属于他们的世界里，过着一个又一个平凡又甜蜜的日子。
